# apps/api — NestJS 12

REST + WebSocket server and a separate BullMQ worker, built from the same codebase.
Compiled with SWC to CommonJS (`dist/`); type-checked with `tsc` (TypeScript 7).

## Layout

```
prisma/schema.prisma        models (uuid v7 ids, camelCase → snake_case via @map)
prisma.config.ts            Prisma CLI config (reads .env)
src/
  main.ts                   HTTP + socket.io bootstrap  → AppModule
  worker.ts                 job processor bootstrap     → WorkerModule
  config/                   env schema (zod) + AppConfig (typed getter). Inject AppConfig, not ConfigService/process.env
  common/
    contract/               @Endpoint, @ReqBody, @ReqQuery, ContractSerializerInterceptor
    auth/                   AuthGuard (global), @CurrentUser, token payload types
    exceptions/             AppException, AllExceptionsFilter (global), zod → fieldErrors
    pipes/                  ParseIdPipe
  infra/                    cross-cutting, shared by API and worker (InfraModule)
    prisma/ redis/ queue/ realtime/ throttler/ push/ i18n/ metrics/ logger.ts
  modules/<feature>/        <feature>.module.ts, .controller.ts, .service.ts, .processor.ts?, *.spec.ts
  generated/prisma/         GENERATED by `prisma generate` — never edit, never commit
test/app.e2e-spec.ts        e2e against docker infra
```

## Writing an endpoint

```ts
const r = contract.projects;

@Controller() // no prefix: paths come from the contract
export class ProjectsController {
  @Endpoint(r.create) // method + path + auth + response serialization
  create(
    @CurrentUser() user: AuthUser,
    @ReqBody() body: RouteBody<typeof r.create>, // parsed by the route's zod schema
  ): Promise<RouteResult<typeof r.create>> {
    // compile-time check against the contract
    return this.projects.create(user.id, body);
  }
}
```

- Use `@Endpoint(route)` for every route. Do not use `@Get/@Post` + DTO classes, `class-validator` or `ValidationPipe`. Only infra endpoints outside the contract (e.g. `/metrics`) use plain decorators — and they must be marked `@Public()`.
- Route params: `@Param('id', ParseIdPipe) id: string`.
- Annotate handler return types with `RouteResult<typeof route>`. The interceptor strips anything not in the response schema, but the type catches mistakes earlier.
- `POST` returns 201 by default; add `@HttpCode(200)` for non-creating POSTs (login, refresh).

## Errors

- Throw `new AppException(ErrorCode.X)` — nothing else. Bind to a form field with `{ field: 'email' }`. Wrap causes with `{ cause }`.
- Never return error objects or set status codes manually. `AllExceptionsFilter` turns everything (zod, Prisma P2002/P2025, Nest HTTP, throttler, unknown) into `ApiErrorBody`. 5xx are logged with the request id; their messages never leak.
- New error code → `packages/contracts/src/errors.ts` + its HTTP status in `errorStatus` (same file) + the message in `packages/i18n` (en + vi).

## Data, cache, jobs, realtime

- **Prisma**: inject `TransactionHost<PrismaTx>` (`infra/prisma/transaction.ts`) and query through `this.db.tx`. Several writes that must succeed together → put `@Transactional()` on the service method; every `db.tx` call below it joins the transaction, across services. Keep side effects (queue jobs, realtime, push, mail) out of the transaction, or run them after it returns: a rollback cannot un-send a push. Processors and scripts outside a request need `@UseCls()` before using `@Transactional()`. `PrismaService` directly is only for infra (health check). Services own queries (no repository layer unless a module grows complex). Every query on user data goes through the ability (see Authorization). Schema change → `pnpm db:migrate --name <change>`; commit the migration. Production runs `pnpm --filter api db:deploy`.
- **Redis**: `@InjectRedis() redis: Redis` (ioredis). Prefix keys by domain: `auth:refresh:<user>:<jti>`, `throttle:*`.
- **Queues**: names + payload types in `infra/queue/queues.ts`. Producer = a service with `@InjectQueue(QueueName.X)`. Consumer = `@Processor(QueueName.X) class extends WorkerHost`, registered **only** in `WorkerModule` (never in `AppModule`). Jobs must be idempotent (retries: 3, exponential backoff). Job ids may not contain `:`.
- **Realtime**: `RealtimeService.toUser(userId, event, payload)` from any service or processor (Redis emitter → every API node). Event names/payloads are typed in `packages/contracts/src/socket.ts`. The gateway (`infra/realtime/realtime.gateway.ts`) only authenticates and joins rooms — keep business logic out of it. Mutations go through REST, not socket messages.
- **Logs**: every request log carries `reqId` (from `x-request-id` or generated) and `userId`. Log with the Nest `Logger`; never log tokens, passwords or full bodies.
- **API docs**: `/docs` (Scalar) and `/openapi.json` are generated from `contract` at boot (`infra/openapi/`); never hand-write OpenAPI or add Swagger decorators. Name a read model in the docs with `.meta({ id: 'Name' })` on its contract schema. On by default except in production (`API_DOCS_ENABLED`).
- **Authorization**: `common/authorization/ability.ts` holds every permission (CASL, roles `USER` | `ADMIN` on `User.role`). Services take the `actor: AuthUser` (not a bare id) and filter with `{ AND: [accessibleBy(defineAbilityFor(actor), action).ofType('Task'), { id }] }`; nothing found → the feature's `*_NOT_FOUND` code. New model or role → add its rules there and a case to `ability.spec.ts`. The role travels in the access token; refresh re-reads the user, so a role change applies within one access-token lifetime.
- **Auth**: global `AuthGuard` fails closed: a handler with no `@Endpoint` still requires auth. Public routes opt out with `auth: false` in the contract or `@Public()` on infra controllers. Two transports, same tokens: `Authorization: Bearer` (mobile) or httpOnly cookies when the client sends `x-auth-mode: cookie` (web; `common/auth/auth-cookies.ts`). Cookie-authenticated writes must carry an allowed `Origin` (`csrf.middleware.ts`). Access JWT (15 min) + rotating refresh JWT tracked in Redis (one use, session per device).
- **Push**: `PushService.toUser(userId, { title, body, data })` (global, `infra/push`) sends to every registered device and drops tokens the push service rejects. Text comes from `translator(user.locale, 'push')`.
- **i18n**: user-facing text (email, push) uses `translator(locale, namespace)` from `infra/i18n` and the recipient's `User.locale`. Never hard-code a message.
- **Rate limit**: global `HttpThrottlerGuard` with Redis storage (120 req/min/IP); it skips websocket contexts because `ThrottlerGuard` writes HTTP response headers. Tighten per route with `@Throttle()`. The storage fails open when Redis is unreachable.

## Config

Rate limits live in `src/config/rate-limits.ts`, time units in `src/common/time.ts`. Rate limits live in `src/config/rate-limits.ts`, time units in `src/common/time.ts`.

Add env vars to `src/config/env.ts` (zod, with defaults where safe) **and** `.env.example`. Read them through `AppConfig.get('KEY')`. If e2e needs it, also list it under `tasks.test:e2e.env` in the root `turbo.json` — Turbo's strict env mode drops undeclared variables (CI sets them on the job, not in a `.env` file). The app refuses to start on invalid env.

## Testing

- Unit: `*.spec.ts` next to the code, only for business rules (see `docs/agents/testing.md`). Instantiate the class with plain mocks (`modules/tasks/tasks.service.spec.ts`); put pure rules in `*.policy.ts` and test them without mocks (`task-reminder.policy.spec.ts`). `pnpm --filter api test`.
- E2E: `test/app.e2e-spec.ts` boots `AppModule` against the docker infra (`pnpm infra:up`). Cover each new route's happy path and its main error code. `pnpm --filter api test:e2e`. The suite clears `throttle:*` in Redis first, so it is repeatable within the same minute.

## Deploy

`apps/api/Dockerfile` (build from repo root) produces one image: default command runs the API, `node dist/worker.js` runs the worker. Scale both horizontally; Redis carries sockets, rate limits, sessions and jobs.
