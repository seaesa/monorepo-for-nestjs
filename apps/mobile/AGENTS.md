# apps/mobile: Expo / React Native

Read the root `AGENTS.md` first. Data layer: `packages/client/AGENTS.md`. Release:
`docs/agents/mobile-release.md`.

## Expo changes every SDK: do not trust your memory

Read the `expo` major in `package.json`, then the matching docs
(`https://docs.expo.dev/versions/v<major>.0.0/`, index at https://docs.expo.dev/llms.txt)
before using any Expo, EAS or React Native API.

## Layout

```
src/
  app/                      Expo Router routes ONLY (every file is a screen; _layout = navigator)
    (auth)/                 signed-out: login, register (redirects home when signed in)
    (app)/                  signed-in: tasks list, tasks/new (modal), tasks/[id], settings
  components/
    ui/                     React Native Reusables (generated, Uniwind); edit, keep structure
    form/                   TextField, FormError
    screen.tsx              scrollable, safe-area page shell
  features/<feature>/components/   feature UI
  device/                   device capabilities shared by features
    notifications/          registerForPush / unregisterForPush, usePushNotifications
    location/               useCurrentLocation
  providers/                AppProviders (client in bearer mode, i18n, query, realtime, theme)
  lib/                      env.ts (t3 env, EXPO_PUBLIC_*), storage.ts (SecureStore + AsyncStorage), utils.ts (cn)
app.config.ts               variants (APP_VARIANT), version (APP_VERSION), EAS project, plugins
eas.json                    build profiles: development, preview (APK), production
```

## Rules

- **Session:** bearer mode; tokens in `expo-secure-store` via `configureClient`. Never read or
  store tokens yourself.
- **Data, forms, text:** same hooks, schemas and i18n keys as web. Submit with
  `onPress={() => void onSubmit()}`.
- **Styling:** Uniwind `className`; no `StyleSheet.create` for app UI, no NativeWind, no raw colors.
  Tokens come from `@repo/theme` (`native.css`; `rgbColors` for JS-only APIs). Theme follows
  `usePreferencesStore().theme` through `Uniwind.setTheme`.
- **UI:** React Native Reusables restyled to match the web component of the same name. Text
  always inside `<Text>` from `@/components/ui/text`. Icons: `lucide-react-native` via `<Icon />`.
- **Lists:** `FlatList` with `keyExtractor`; put headers in `ListHeaderComponent`; never a list
  inside a `ScrollView`.
- **Permissions:** ask at the moment of use (location when attaching it, notifications after
  sign-in), handle "denied" in the UI, and declare the purpose text in `app.config.ts` plugins.
- **Push:** the device token is registered after sign-in and unregistered _before_ sign-out.
  Pushes carry `data.url` (an app path); tapping one opens it.
- **Native config:** `ios/` and `android/` are generated (CNG); configure in `app.config.ts`.
  Native modules need a development build (`eas build --profile development`).
- **Typed routes:** `.expo/types/router.d.ts` is generated by Metro; after adding a route, start
  Metro once if `tsc` rejects an href.

## Commands (inside `apps/mobile`)

```bash
npx expo install <pkg>        # ALWAYS for native/Expo packages
pnpm dev                      # expo start
pnpm check-types              # lint runs from the repo root: pnpm lint
npx expo-doctor               # must pass
```
